# QWE Trader by Molly Paradise 1.21.0 — учёт перепродажи (Arizona RP, MoonLoader)

> **Как устроено.** Автообновление вынесено в отдельный небольшой файл-загрузчик `qwe_trade.lua`, а весь код скрипта — в защищённом файле ядра `qwe_core.dat` (скомпилированный байт-код LuaJIT). Загрузчик проверяет версию и сам обновляет ядро с GitHub.

## Установка
Нужны: MoonLoader, SAMPFUNCS, **mimgui**, **encoding**.

1. Скачайте архив **qwe-trader-1.21.0.zip** со страницы [Releases](https://github.com/thepleinairstudio/qwe-trader/releases/latest) (или зелёная кнопка Code → Download ZIP).
2. Скопируйте содержимое папки `moonloader` из архива в папку `moonloader` игры:
   - `moonloader/qwe_trade.lua` — загрузчик (запуск и автообновление);
   - `moonloader/qwe_core.dat` — ядро скрипта (защищённый байт-код, вся логика);
   - `moonloader/config/qwe_trade/` — база предметов Arizona (`items.txt`, `vehicles.txt`, `accessories.txt`) и звуки (`sounds/`).
3. Зайдите в игру и наберите `/qwe`.

Если положить только `qwe_trade.lua`, загрузчик сам скачает ядро, базу предметов и звуки.

## Автообновление
Загрузчик `qwe_trade.lua` при запуске проверяет `version.json` в этом репозитории и, если вышло новое ядро, сам скачивает `qwe_core.dat` и перезапускается. Прошлое ядро остаётся в `qwe_core.dat.bak`, данные — в `config/qwe_trade/backup/`. Отключается в настройках («Автообновление»), там же кнопка «Проверить сейчас» и история версий («Что нового?»).

## Для разработки
Исходный код ядра в репозитории не публикуется. Сборка ведётся у автора: исходник (UTF-8) переводится в Windows-1251 и компилируется в байт-код `qwe_core.dat` тем же LuaJIT игры; загрузчик `qwe_trade.lua` остаётся открытым.
- `tools/make_sounds.py` — генератор звуков уведомлений.

## Управление
- `/qwe` — главное окно, `F3` — быстрая покупка, `Esc` — закрыть.
- Цены: `150000`, `150к`, `1.5кк`, `2kk`.

## Вкладки
- **Склад** — купленное; «Продал» — вписать, за сколько продал, итог считается сразу.
- **Из инвентаря** — кнопка «Сканировать инвентарь», затем открыть инвентарь (Y). Читается один раз, потом скрипт перестаёт слушать.
- **Логи** — продажи и покупки (ПКМ по продаже — вернуть на склад), список дней с итогами, записи дня, поиск по названию за все дни (сколько куплено, по какой средней цене, итог). Каждый день ещё и в файле `config/qwe_trade/logs/ГГГГ-ММ-ДД.txt`.
- **Настройки** — шрифт (3 варианта, применяется перезапуском скрипта), комиссия, обновление базы предметов.

Данные: `moonloader/config/qwe_trade/data.json`.

- «Сначала дорогие» сортирует по стоимости всей позиции (цена x количество).
- «Лавка» после скана сразу показывает, что выставится: зелёный — вещь найдена в инвентаре и цена есть, жёлтый — нет цены или в инвентаре меньше штук, красный — вещь не найдена. Наведите на красное — будет причина и как исправить, а кнопка «Исправить» даёт выбрать нужную вещь из инвентаря.
- Скан больше не предлагает добавить на склад вещь, которая там уже есть под немного другим названием (например, «Часы Gucci» и Часы с кавычками).
- Если часть штук осталась у вас (например, 74 заточки из 80), это больше не ошибка: скрипт выставит то, что есть в инвентаре, и просто напишет об остатке.
- «В лавке» теперь определяется по самой игре: выставленная вещь в инвентаре серая. Сняли с продажи вручную, убрали лавку, продалось — отметка пропадает сама, и вещь можно выставить снова. Серые ячейки скрипт при выставлении не трогает.
- Вверху «Лавки»: стоит ли лавка и сколько позиций в ней сейчас.
- Скан инвентаря больше не ждёт кнопку обновления: скрипт держит живую копию инвентаря и сканирует за пару секунд. Внизу экрана — полоска со временем скана и проверки «Информации».
